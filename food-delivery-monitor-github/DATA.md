# 数据说明

`data/demo.csv` 是为这个作品生成的合成订单，不来自真实企业、客户或交易。编号带有 DEMO 前缀。2024 年 1—4 月的数据被刻意设计为能展示基线、平稳、上升、下降状态，不能作为真实经营结论或模型有效性的证明。

源代码与演示页面均清晰标注合成样本。个人上传的 CSV 在浏览器内计算，不通过网络提交到 GitHub 或其他数据处理服务；网站托管仍由 GitHub Pages 提供。

`data/upload-template.csv` 只有表头，没有订单。必需字段与格式见页面上的 CSV 准备指南。原始样本文件及带原始订单的本地单文件 HTML 未包含在本包中。

如果以后改用其他公开数据，请在此补充来源链接、作者、许可、获取日期、清洗规则，并确认允许公开再分发。不要仅凭「能下载」推断允许再分发。
